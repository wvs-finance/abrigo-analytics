## 2. The x402 per-query price (cost multiplier)

`data/raw/e10_gsps/x402/x402_payment_required.json` — the decoded The
Graph Gateway x402 `payment-required` header probe. Verified flat
**$0.01 USDC per query** (`exact` scheme), re-verified exactly at E10.0.
The cost stream is `cost = Q × $0.01 × FX`; the $0.01 multiplier is real
and constant (it carries no fantasy posture — fantasy-firewall enforced).

## 3. The simulated quantity — Q

Q (the daily/monthly query-arrival process) is generated by the R6 NHPP
simulation engine (`simulations/e10_gsps/modules/nhpp_engine.py`), a Cox
/ doubly-stochastic NHPP calibrated to the user's own observed query-log
trace (E10.1 calibration note §2 — ~60–130 priceable queries/month
centre). The engine derives a deterministic per-`(currency, year,
month)` seed (`_cell_seed`), so a given cell's Q is reproducible
bit-stably and is independent of the FX path (spec §6.4 — Q ⊥ FX in the
primary specification).

## 4. Tier 1 — the panel parquet

`data/panels/e10_gsps_panel.parquet` — the assembled 5-currency × 30-month
E10 panel (150 cells). Per-cell columns: the X-side FX realized variance
(spec §3.2), the Y-side cost-stream realized variance (§5.2), the exact
§4.2 three-way log-variance decomposition (`var_total`, `var_fx`,
`var_q`, `cov_term`, `identity_residual`, `fx_variance_share`), and the
common-grid bookkeeping (`grid_index_length`, `n_fx_trading_days`,
`n_surviving_days`, `material_gap`). `data/panels/` is gitignored — the
parquet is re-derivable via the Tier-3 builder.

## 5. Tier 3 — reproducibility contract

`scripts/build_e10_gsps_panel.py` re-derives the Tier-1 panel from the
frozen Tier-2 FX snapshots:

```
python scripts/build_e10_gsps_panel.py                    # build Tier 1
python scripts/build_e10_gsps_panel.py --verify-against-tier1
```

**Round-trip tolerance (CORR-E10P-7):**

- `x_realized_variance` (the real FX panel cell) re-derives **bit-exact**
  — it is a pure function of the frozen FX bytes.
- The fixed-seed simulator-derived cells (`y_realized_variance` and the
  decomposition terms) re-derive within a **1e-9 relative tolerance** —
  the NHPP engine is referentially transparent in `(currency, year,
  month)` via its deterministic seed; the only divergence is
  floating-point summation order.

The Phase-3 build verified the round-trip PASSES for all 150 cells.

## 6. The common differencing grid (CORR-E10P-3)

The exact §4.2 identity `Var(Δlog cost) = Var(Δlog FX) + Var(Δlog Q) +
2·Cov` holds cell-by-cell exactly only on a common X/Q sub-monthly
differencing grid. The grid is the daily FX trading-day index; the
simulator emits one daily Q count per FX day. Per cell, zero-query days
(zero cost, undefined `Δlog cost`) are dropped from X and Q on the SAME
surviving index, preserving the common grid — the identity remains exact
on every surviving consecutive pair. The index-alignment verification
artifact is `notebooks/e10_gsps/diagnostics/E10.2_grid_alignment.json`
(150 cells, all aligned).
